にゃんこ体重管理室 PWA版

使い方:
1. このフォルダ一式を同じ階層のままWebサーバーへ置きます。
2. HTTPSのURL、または localhost で開きます。
3. Chrome / Edge で開くと、アドレスバー付近の「インストール」または画面内のボタンからPCへ追加できます。

同梱物:
- index.html
- manifest.webmanifest
- sw.js
- icons/icon-192.png
- icons/icon-512.png

注意:
- file:/// で直接開くと service worker が動かず、インストール不可です。
- データ保存はブラウザのローカル保存です。
